    资料存在哪、如何导入

    保存在本机哪个文件

    都在项目的 data/ 目录里，不会上传到网络。

    • data/profile.json：本页的网申填写资料（姓名、教育、项目等）
    • data/store.json：应聘记录列表
    • data/resume/：简历原件与笔记
    • data/screenshots/：投递截图

    首次启动会从 data/profile.example.json 复制一份空模板生成 profile.json。个人文件已加入 .gitignore，提交仓库时不会带上你的内容。

    导入格式

    请导入 UTF-8 的 .json 文件，与点「导出资料」得到的备份相同。导入会整份替换当前网申资料，建议先导出备份。

    根对象必须是：

    {
  "version": 1,
  "entries": [ /* 最多 1000 条 */ ]
}

    每条 entries 字段：

    • id：字符串，不能重复（可用 basic-name 或 UUID）
    • group：分组名，如 基本信息、硕士、项目：示例项目
    • label：字段名称，如 姓名
    • value：填写内容，空字符串表示未填
    • aliases：字符串数组，网申识别别名，如 ["名字", "name"]
    • source：备注，会显示在字段下方；没有备注必须是空字符串，不要填「简历」
    • date：布尔值，true 表示日期备忘、不自动填入
    • pending：布尔值，true 表示待确认、暂不推荐填入

    示例（一条）：

    {
  "version": 1,
  "entries": [
    {
      "id": "basic-name",
      "group": "基本信息",
      "label": "姓名",
      "value": "张三",
      "aliases": ["名字", "name"],
      "source": "",
      "date": false,
      "pending": false
    }
  ]
}

    也可以把简历和提示词发给 DeepSeek，把生成的 JSON 粘贴到「导入」弹窗中。

    最省事的做法：先点「导出」得到标准文件，改里面的 value 后再导入。
